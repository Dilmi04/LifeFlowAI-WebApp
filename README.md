# 🩸 LifeFlow AI

LifeFlow AI is an AI-powered web application designed to improve emergency blood donation coordination by intelligently connecting hospitals with nearby eligible donors.

## 🚀 Project Overview

During emergency situations, hospitals often struggle to find suitable blood donors quickly. LifeFlow AI addresses this challenge by providing a centralized platform where hospitals can raise blood requests and donors can respond instantly. The system uses intelligent prioritization and AI assistance to reduce response time and improve efficiency.

## 🎯 Key Features

- Donor and Hospital role-based system
- Emergency blood request creation
- Smart donor alert system (prototype-level)
- AI-powered chatbot for guidance and FAQs
- Blood demand insights and analytics (mock data)
- Interactive dashboards for donors and hospitals
- Clean and responsive web UI based on Figma design

## 🧠 AI Integration

- AI Assistant (Chatbot) for:
  - Donor eligibility guidance
  - Hospital support
  - Emergency-related FAQs
- Basic demand pattern insights for hospitals
